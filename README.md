# Aditya Dixit — Portfolio

A static, NDA-safe portfolio for a Senior Frontend Engineer. It uses no client code, client product links, screenshots, proprietary diagrams, or confidential metrics.

## Run locally

Open `index.html` in a browser, or use VS Code's Live Server extension if it is installed.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `<your-github-username>.github.io`.
2. Put these files at the repository root and push them to the `main` branch.
3. In the repository, open **Settings → Pages** and choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. The site will be available at `https://<your-github-username>.github.io` after GitHub finishes deploying it.

Before publishing, review all public contact details and every experience line against your employment agreements.
